# 라시안컷 — 로블록스 스튜디오 버전

`Rasyancut.rbxlx` 를 **Roblox Studio** 로 열고 ▶ Play(F5) 하면 됩니다. (Studio → File → Open from File)

## 들어 있는 것
- **인트로 → 메인**: 검정 + 금색 홀로그램 화면, 모든 화면 전환에 셔터 + 회전 아이콘 연출
- **공지**: 웹 공지(패치 노트) 28개
- **사령관 통신**: 9명, 주제별 질문 목록(답변 5개 중 중복 없이 랜덤), 관계 탭, 발신자 표시 제한은 직접 입력(키워드)
- **3D 월드**: 회장실(100F) → 복도(엘리베이터·계단실) → 95층(크리토스 퀘스트) → 옥상(난간 없는 흰 바닥, 하얀 외벽, 고장 난 수신탑)
  - 가까이 가면 뜨는 **E 키(조사/대화)** 로 상호작용, 이동 시 층수 연출
  - 월드 안에서 **M 키** 또는 왼쪽 위 MENU 버튼으로 메인 화면 열기

## 구조
| 위치 | 내용 |
|---|---|
| `ServerScriptService/World` | 3D 월드 생성, 이동·퀘스트·엘리베이터 (`roblox/src/World.server.lua`) |
| `StarterPlayerScripts/Client` | 모든 UI (`roblox/src/Client.client.lua`) |
| `ReplicatedStorage/RSC_Data` | 공지·사령관 목록·대화 데이터(모듈 스크립트, 자동 생성) |

## 다시 만들기
`node tools/build-roblox.js` — 웹의 공지와 `data/cmd/*` 가 바뀌면 이 명령으로 `.rbxlx` 를 새로 만듭니다.

## 웹 버전과 다른 점 / 아직 없는 것
- 관측소, 신호기 연출(눈·웃음·CRT), 설정집, 소설 본문은 옮기지 않았습니다.
- 인물은 단순한 블록 모양이고, 소리(효과음)는 없습니다.
- 옥상은 난간이 없어서 실제로 떨어질 수 있습니다(떨어지면 옥상 계단 앞에서 다시 시작).
